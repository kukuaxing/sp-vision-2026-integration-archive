## 二、硬件架构

### 2.1 电机布局

```
CAN1 (大疆)                             CAN2 (大疆 + 达妙)
├── M3508 × 4   ← 底盘麦轮              ├── M3508 × 2   ← 摩擦轮 (一正一反)
├── M2006 × 2   ← 履带辅助电机           ├── DMmotor[0]  ← 左折叠腿关节
├── M2006 × 1   ← 供弹拨盘电机           ├── DMmotor[1]  ← 右折叠腿关节
├── M6020 × 1   ← 云台Yaw关节           └── DMmotor[2]  ← 云台Pitch关节
```

### 2.2 串口分配

| 串口 | 外设 | 波特率 | 说明 |
|------|------|--------|------|
| UART1 | 裁判系统 | 115200 | 接收比赛数据 + 发送UI |
| UART4 | XUC视觉上位机 | 460800 | 高速自瞄数据收发（无）+ IMU数据 |
| UART5 | 超级电容 | 115200 | 电容能量/电压/电流 |
| UART6 | 遥控器/键鼠接收机 | 921600 | 新版21字节协议 CRC16校验 |

### 2.3 关键硬件经验

- **CAN终端电阻必须120Ω**：达妙电机没有内置终端电阻，与大疆电机混用时需要特别注意。CAN总线H-L间插上单片机应为60Ω，断开应为120Ω。
- **CAN线不能弯折成环**：会极大影响通信质量。
- **达妙电机CAN ID限制**：ID ≥ 0x201 视为大疆电机，达妙ID需在 0x01~0x10 范围。
- **线材规划要合理**：线不在长、合适最好，缠绕会对CAN/串口通信带来极大干扰。
- **排查问题时先查硬件**：主控→CAN线→CAN板→电机的链路逐一排查。
- **电源线红正黑负，方正圆负**：接线前一定要检查正负，不然插一个爆一个。
- **CH340的贴片电阻**：有R6的能导电。注意R4，R5的电阻方向，横着焊成竖的会闹鬼（自收自发）

## 三、软件架构（FreeRTOS 任务调度）

### 3.1 任务一览

| 任务名称 | 周期 | 优先级 | 栈大小 | 职责 |
|----------|------|--------|--------|------|
| **DecodeTask** | 1ms | 5 (最高) | 128 | 解包遥控器、DBUS、超电、裁判系统、IMU、XUC视觉 |
| **MotorUpdateTask** | 2ms | 3 | 256 | CAN反馈解析、达妙关节解算、功率限幅应用 |
| **ControlTask** | 2ms | 4 | 128 | 核心控制：功率调度 + 防卡弹状态机 + 底盘/云台/射击更新 |
| **CanTransimtTask** | 2ms | 2 | 256 | 集中发送CAN控制帧 |
| **UiSendTask** | 30ms | 2 | 256 | 裁判系统UI刷新 + 超电编码 + 达妙G键使能 |
| **ArmTask** | 30ms | 1 | 128 | 达妙电机安全启动（CTRL键触发）+ 故障自动重试 |

### 3.2 调度设计思想

- **解码优先**：接收数据的任务（DecodeTask）优先级最高（5），确保数据不丢失。
- **控制紧跟**：ControlTask 优先级 4，拿到最新数据后立即计算。
- **发送靠后**：CanTransimtTask 优先级 2，避免高优先级任务被发送阻塞。
- **安全启动**：ArmTask 优先级最低（1），只在空闲时使能达妙电机，避免上电冲击。

### 3.3 数据流

```
UART DMA RX (中断)
    ↓
FreeRTOS 队列
    ↓
DecodeTask (1ms) ───── 解包所有外设数据 ────→ 全局变量更新
    ↓
ControlTask (2ms) ───── 读取RC/裁判/视觉数据 ─→ 运动学解算 + PID
    ↓
MotorUpdateTask (2ms) ─ 计算电流输出 + 功率限幅 ─→ CAN 发送缓冲区
    ↓
CanTransimtTask (2ms) ─ 集中发送CAN帧 ─────────→ 电机执行
```

## 四、电机控制模型

### 4.1 大疆电机（motor.cpp）

支持电机类型：M3508 / M3510 / M2310 / EC60 / M6623 / M6020 / M2006

| 控制模式 | 适用场景 | 控制链路 |
|----------|----------|----------|
| **SPD** | 底盘轮电机、履带电机 | 增量PID速度环 → 电流输出 |
| **SPD_SHOOT** | 摩擦轮 | 增量PID速度环（无死区，持续输出） |
| **POS** | 云台Yaw（编码器反馈） | 位置环(卡尔曼滤波) → 速度环 → 电流输出 |
| **POS_IMU** | 云台Yaw（IMU反馈） | 位置环(IMU角度) + 底盘旋转前馈 → 速度环 → 电流 |
| **ACE** | 供弹拨盘 | 速度环 + 自动停位（检测到指定角度后停止） |

### 4.2 达妙电机（HTmotor.cpp）

支持模式：MIT / POS_DM / SPD_DM

核心控制函数链：
```
DMmotor_Ontimer() ──→ 位置/速度误差计算
    ↓
PID 计算 → 力矩电流
    ↓
DMmotor_transmit() ──→ CAN扩展帧发送 (MIT模式)
```

关节参数：
- Kp = 10.0f, Kd = 0.6f（全局默认值）
- 可通过G键强制使能覆盖

**安全启动流程**（ArmTask）：
1. 检测使能按键（CTRL/遥控器custom_key_l）
2. 逐个检查电机err状态（≥8为故障）
3. 故障电机先发送 `CMD_CLEAR_MODE` 清除错误
4. 正常电机发送 `Motor_Start()` 使能
5. 最多重试20次，每次间隔100ms
6. 全部正常后设置 `ctrl.init_DM = 1`

## 五、核心控制逻辑（control.cpp）

### 5.1 底盘运动学（CHASSIS）

```
输入: speedx, speedy, speedz (世界坐标系)
    ↓
Keep_Direction() —— 云台跟随补偿（cos/sin旋转矩阵）
    ↓
麦轮逆解算:
  左前 = +speedx + speedy - speedz
  右前 = -speedx + speedy - speedz
  右后 = -speedx - speedy - speedz
  左后 = +speedx - speedy - speedz
    ↓
达妙腿关节限位保护:
  DMmotor[0].setPos ∈ [0, 0.95]
  DMmotor[1].setPos ∈ [-0.95, 0]
```

### 5.2 云台控制（PANTILE）

**POS 模式**（编码器）：
```
鼠标/摇杆输入 → 累加到 mark_yaw (8192编码器范围)
  → 限幅到 [0, 8192)
  → can1_motor[7].setangle
```

**POS_IMU 模式**（视觉自瞄）：
```
XUC 视觉数据有效时:
  自瞄激活 → setangle = XUC目标Yaw
           → Pitch = XUC目标Pitch
  手动控制 → setangle ±= 鼠标输入
           → Pitch ±= 鼠标输入
           
Pitch限幅: [-0.25, 0.50]
Yaw限幅: [-180°, 180°]
```

### 5.3 射击控制（SHOOTER）—— 智能防卡弹状态机

这是步兵代码的核心创新点，状态机如下：

```
                    ┌──────────────────────────────────┐
                    │          NORMAL (正常)             │
                    │  摩擦轮已启动 + 收到开火指令        │
                    │  → 拨盘电机正转 6000rpm            │
                    │  → 监测电流是否超 JAM_CURRENT      │
                    └───────┬──────────────┬────────────┘
                            │              │
                电流正常    │              │ 电流 > 9000 持续 1.5s
                持续供弹    │              │
                            │              ↓
                            │  ┌───────────────────────────┐
                            │  │    JAM_BLOCK (卡弹反转)    │
                            │  │  拨盘电机反转 -1500rpm     │
                            │  │  持续 2.1s                │
                            │  │  结束后自动恢复 NORMAL     │
                            │  └────────────┬──────────────┘
                            │               │
                            │   2.1s 后     │
                            │               ↓
                            └────── 恢复正常供弹 ──────────┘
```

关键参数：
- `JAM_CURRENT_THRESHOLD = 9000`（电流阈值）
- `JAM_DETECT_TIME_MS = 1500`（判定卡弹时间）
- `JAM_BACK_TIME_MS = 2100`（反转退弹时间）
- 摩擦轮速度必须 > 5000rpm 才允许供弹（安全保护）

### 5.4 功率调度（ControlTask 主循环）

```
读取裁判系统功率上限 chassis_power_limit
    ↓
根据 flag_shoot 状态偏置:
  flag_shoot=1 (激进) → limit + 150W
  flag_shoot=2 (保守) → limit - 10W
  flag_shoot=0 (正常) → limit
    ↓
powerLimiter.SetMaxPower(judgeLimit)
    ↓
heatLimiter.Update() —— 热量检测
    ↓
xuc.Encode() —— 上位机通信打包
    ↓
rc.Update() —— 遥控/键鼠指令解析
    ↓
chassis.Update() / pantile.Update() / shooter.Update()
```

## 六、动态功率调度（PowerLimiter）

基于香港科技大学 ENTERPRIZE 战队开源方案，采用递归最小二乘法（RLS）在线辨识电机功率模型：

```
电机功率模型: P = k1·|ω| + k2·τ² + k3
  k1: 摩擦损耗系数
  k2: 铜损耗系数
  k3: 静态损耗
```

**调参流程**（参考哨兵文档）：
1. 关闭 RLS，分别在静止、普通移动、抵墙三种工况下调节 K1/K2/K3
2. 观察预测功率与实际功率的匹配程度
3. 开启 RLS 进行在线自适应优化

**能量反馈环**：
```
basePower + Kp × (targetEnergy - currentEnergy) → 动态调整功率上限
```

## 七、热量管理（HeatLimiter）

```
裁判系统反馈:
  Q1 = 当前枪管热量
  Q0 = 热量上限
  冷却速率 = 每秒冷却值

控制策略:
  Q1/Q0 > 90%  →  禁止射击 (CanFire = false)
  Q1/Q0 < 50%  →  恢复满速射击
  中间状态     →  按比例缩放拨盘电机转速 (最低30%)
```

## 八、通信协议

### 8.1 遥控器协议（Decode_NEW）

21字节帧结构（0xA9 0x53 帧头 + CRC16）：

| 字节 | 内容 |
|------|------|
| 0-1 | 帧头 (0xA9, 0x53) |
| 2-6 | 遥控器通道 ch[0]~ch[3] |
| 7-8 | 开关 S0, pause_key, custom_key, go_up |
| 9 | 拨轮 wheel |
| 10-15 | 鼠标 X, Y, Z |
| 16 | 鼠标按键 (左/右/中) |
| 17-18 | 键盘按键位图 (W/S/A/D/SHIFT/CTRL/Q/E/R/F/G/Z/X/C/V/B) |
| 19-20 | CRC16 校验 |

### 8.2 XUC 视觉协议

**接收包**（上位机→下位机）：
- 控制标志、射击标志
- 目标 Yaw/Pitch（rad）
- IMU 姿态（pitch/yaw）

**发送包**（下位机→上位机）：
- 模式（空闲/自瞄/小符/大符）
- 机器人ID、子弹速度、子弹计数

### 8.3 裁判系统协议（2026版）

完整支持2026版裁判系统协议：
- 比赛状态 (0x0001) / 比赛结果 (0x0002) / 血量 (0x0003)
- 场地事件 (0x0101) / 补给信息 (0x0102) / 飞镖信息 (0x0103)
- 机器人状态 (0x0201) / 功率热量 (0x0202) / 位置 (0x0203)
- 增益信息 (0x0204) / 空中支援 (0x0205) / 伤害信息 (0x0206)
- 射击信息 (0x0207) / 子弹金币 (0x0208) / RFID (0x0209)
- 飞镖指令 (0x020A) / 机器人坐标 (0x020B) / 雷达标记 (0x020C)
- 哨兵信息 (0x020D) / 双倍易伤 (0x020E)

## 九、遥控/键鼠操作完整映射

模式切换由遥控器 **S0 拨码开关** 决定（`RC::Update()`）：

| S0 档位 | 模式 | 说明 |
|---------|------|------|
| **C (0)** | PC 模式 | 键鼠控制 |
| **N (1)** | RC 模式 | 遥控器控制 |
| **S (2)** | AUTOAIM 模式 | 视觉自瞄接管（暂时没用） |

### 9.1 遥控器操作（RC::OnRC）

| 控件 | 功能 | 说明 |
|------|------|------|
| **左拨杆 ch[2]/ch[3]** | 底盘前后左右平移 | 速度 = ch × max_speed / 330 |
| **拨轮 wheel** | 底盘旋转（speedz） | 速度 = -wheel × max_speed / 330 |
| **右拨杆 ch[0]/ch[1]** | 云台 Yaw/Pitch 或 腿关节升降 | 由 custom_key_l 切换 |
| **custom_key_l（左功能键）** | 切换云台/腿关节控制模式 | 按下翻转状态：ON→控制DM腿关节（ch[1]调节高度），OFF→控制云台（ch[0]Yaw, ch[1]Pitch） |
| **custom_key_r（右功能键）** | 摩擦轮开关 | 按下翻转状态：ON→摩擦轮开启 + 配合go_up供弹，OFF→关闭 |
| **go_up（肩键）** | 履带电机启动 + 供弹触发 | 履带电机 can1[4]=-7000, can1[5]=7000；PC/自瞄模式下同时作为开火键 |
| **pause_key（急停键）** | 紧急停止 | **最高优先级**：全部14个电机 + 3个达妙电机速度归零 |
| **S0 拨码开关** | 模式切换 | C=键鼠, N=遥控器, S=自瞄 |

**遥控器腿关节控制逻辑**（`custom_key_l` 切换）：
```
custom_key_l ON:
  DMmotor[0].setSpeed = 4.8
  DMmotor[1].setSpeed = 4.8
  DMmotor[0].setPos += ch[1] / 110000   ← 左腿
  DMmotor[1].setPos -= ch[1] / 110000   ← 右腿

custom_key_l OFF:
  云台 Yaw:  ch[0] × yaw_speed / 660
  云台 Pitch: ch[1] × pitch_speed / 660
```

### 9.2 键鼠操作（RC::OnPC）

| 按键 | 功能 | 说明 |
|------|------|------|
| **W/A/S/D** | 底盘前后左右移动 | Ramp 软加速（步进 = speed_limit × 0.1），松键立即归零 |
| **鼠标 X/Y** | 云台 Yaw/Pitch 跟随 | 鼠标移动量 → Control_Pantile() |
| **鼠标左键** | 开火 | 需摩擦轮已启动（`press_l` 触发 `fire_hold_cnt=30`） |
| **鼠标右键** | 自瞄请求 | `press_r` + `xuc.fire_auto` 联合判断 |
| **Z** | 折叠腿上升 | 步进 0.0025，上限 0.95 |
| **C** | 折叠腿下降 | 步进 0.0025，下限 0.0 |
| **X** | 小陀螺模式切换 | ON→speedz = spin_speed_limit；OFF→Q/E 控制旋转 |
| **Q** | 底盘左旋转 | 仅非小陀螺模式（`x_toggle=OFF`） |
| **E** | 底盘右旋转 | 仅非小陀螺模式（`x_toggle=OFF`） |
| **F** | 摩擦轮开关 | ON→can2[0][1] = ±shoot_speed（默认6000）；UI同步显示 |
| **R** | 履带电机开关 | ON→can1[4]=-4000, can1[5]=4000；UI同步显示 |
| **V** | 射击状态切换 | ON→激进（功率+150W），OFF→保守（功率-10W） |
| **G** | 达妙电机强制使能 | `UiSendTask` 中检测，给全部达妙电机发送 `Motor_Start()` |
| **B** | 裁判系统UI刷新开关 | 按下触发 `judement_start=true`，开始通过裁判系统发送UI数据 |
| **CTRL** | 达妙电机初始化重试 | `ArmTask` 中检测，执行清错 + 重新使能流程（最多20次） |

**键鼠底盘速度模式联动**（`flag_shoot` + `GetChassisSpeedScale()`）：

| flag_shoot 状态 | V键 | 底盘速度倍率 | 功率偏置 |
|:---:|:---:|:---:|:---:|
| 0（默认） | — | ×0.9 | 裁判系统原始值 |
| 1（激进） | V=ON | ×1.5 | +150W |
| 2（保守） | V=OFF | ×0.9 | -10W |

## 十、安全保护机制

| 保护机制 | 触发条件 | 响应 |
|----------|----------|------|
| **急停** | 遥控器 pause_key = 1 | 全部电机（大疆+达妙）速度归零 |
| **温度保护** | 电机温度 > 70°C | 该电机 setspeed = 0 |
| **离线检测** | 扭矩电流连续20帧不变 | 标记为 DISCONNECTED/UNCONNECTED |
| **摩擦轮保护** | 摩擦轮速度 < 5000rpm | 禁止供弹 |
| **卡弹反转** | 拨盘电流超9000持续1.5s | 反转2.1s自动恢复 |
| **热量限制** | 枪管热量 > 90%上限 | 禁止射击 |
| **功率限制** | 计算功率 > 裁判系统限制 | 等比缩减电机输出 |
| **Pitch限位** | setPos 超出范围 | 限幅到 [-0.25, 0.50] |
| **腿关节限位** | DM0/DM1 setPos 超范围 | 限幅到合理区间 |
| **CAN错误恢复** | CAN总线错误锁死 | 清除错误标志位，1s内反复则不再恢复 |

## 十三、开发建议

1. **先用 AI 理解代码**：在 STM32F405 目录下维护 Markdown 说明文件，让 AI 每次都有完整上下文
2. **不要完全依赖 AI**：使用 AI 前做好备份/Git 提交，使用后务必人工 Review
3. **遇到问题先查硬件**：主控→CAN线→CAN板→电机的链路逐一排查
4. **安全第一**：调试时用积木架起底盘，关电手速要快
5. **善用工具**：万用表查终端电阻、热成像仪查短路、Live Watch 调 PID
6. **拥抱 AI 时代**：使用 VS2026 + VisualGDB + Copilot 辅助开发
