# 当前导航与视觉任务衔接源码

本目录归档当前开机监管、地图配准、导航任务管理、状态查看，以及运行入口直接引用/校验的控制与规划源码、配置和单元测试。保留小电脑现有目录名及文件字节，避免改变 `map_route/sources.json` 中34项已审核源码的SHA256；带日期的依赖目录名来自现有部署，不代表此次新建了工程副本。

实际完整安装位于小电脑 `/home/rcsdart/rm27/navigation`。地图/先验点云/ROS安装产物、运行日志和第三方构建工作区不进入本Git归档。仅克隆本仓库不会获得该导航安装环境；还需准备ROS 2 Humble、Livox驱动/SDK、FAST-LIO、GTSAM、地图定位backend以及本车rm27_sensor_bridge安装包，并恢复原地图、传感器配置和P00配准。此处不宣称能只靠一次clone复原整套导航部署。

- `boot/`：现用服务入口、定位启动监管及P00配准。
- `mission/`：准备、遥控双上出发、任务点发令及返航策略，见[任务说明](mission/README.md)。
- `map_route/`：地图路线、固定源校验及导航执行适配。
- `localization/`、`real_bringup/`：当前传感器/定位启动配置。
- 其他源码：上述运行入口实际引用的现有模块。

归档验证仅运行离线/虚拟设备检查，没有启动导航、相机或真实发射，也没有重新认证整场任务。现场使用仍须按当前硬件、地图和起点条件验收；车上实际电控源码范围见[固件说明](../firmware/README.md)。

当前导航电机转速限幅为 **5500 rpm**（固件6000 rpm限幅的91.7%），`map_route/global_plan.json`、`firmware_profile.json`与路线生成器默认值保持一致。规划速度上限仍为1.8 m/s，加速度1.1 m/s²、减速度1.5 m/s²；提高转速限幅主要增加混合方向纠偏时的余量，不表示全程速度按比例增加。实测峰值与平均速度仍以里程计为准。

当前跟随器限制正常平移指令的加速度变化率为6 m/s³，过弯参考速度为0.20 m/s。拐角方向使用当前进度至前8 cm的局部弦向量过渡，额外减速余量为8 cm（原10 cm；传感数据年龄和控制响应的时间余量保留），弯后30 cm内继续约束提速；参考路线点位保持原样。终点从最后50 cm逐渐混入位置与速度反馈，最后80 cm增加考虑数据年龄、响应余量与加速度变化限制的制动速度包络；位置纠偏增益为3 /s。当前位置与短时预测位置均在3.5 cm内、指令与实测速度较低时进入收零；偏离3.5 cm恢复纠偏。最终置零须满足本周期及下一周期的加速度变化限制，且指令速度不超过3 mm/s。到位仍检查实际速度，并保留原有停稳观察和任务许可。速度/转速限幅和故障撤销许可优先于平滑，紧急STOP不经过缓停。

离线模型对比覆盖8组响应滞后、比例误差、控制周期与厘米级定位噪声。名义往返流程（含固定5秒任务等待）由63.84秒降至57.76秒，最大横向偏差3.71 cm降至2.02 cm；8组最大横向偏差4.72 cm。对比记录位于 `logs/navigation-profile-comparison.json`，这些数值来自简化模型，不能代替实车速度、轮胎打滑及通道净空验收。新日志包含导航速度指令、分段进度、终点收速比例，便于现场比较。


本轮纯断电换电后的只读审计确认：内核boot ID更新，两个服务自动启动且重启次数0，视觉/任务子链只启动一次，约上电15.3秒进入READY_WAIT_BOTH_UP，相机、电控姿态和雷达定位持续更新；没有通过人工重启服务帮助该次冷启动完成。证据为 `logs/cold-boot-audit.json`，仅证明本次现场冷启动通过。

随后在该次冷启动审计完成后，更新了拐角的8 cm减速余量和方向预瞄。该修改不提高弯速、加速度或直线速度上限，也不改变路线点位；名义模型往返（含固定5秒任务等待）57.76秒降至约55.98秒。完整压力对比见 `logs/navigation-corner-comparison.json`；其中额外的高滞后/比例偏差叠加噪声案例仍有超过6 cm的偏差，不能把离线检查解释为真实通道净空认证。该次拐角更新的实车效果待现场验证。


终点更新前，实车日志显示任务点前约4 cm处，规划速度0.08–0.10 m/s而里程计速度接近零约1秒；返程曾越过起点约5 cm后回拉。低速执行受阻是待实测的解释，未据此修改电控PID。此次终点优化保留3.5 cm到位范围、原有实测速度门限和后续停稳观察，视觉与路线拐角参数不变。新增日志字段为 `endpoint_speed_cap_m_s`、`endpoint_predicted_error_m`、`terminal_settling`。

离线验证增加显式观测滞后和低速起步阈值模型，前者与数据年龄标记分开建模；后者是压力测试假设。100 ms观测滞后案例由56.96秒降到约54.82秒，返程过冲约7.68 cm降至约0.22 cm；无观测滞后的名义模型收益较小。这些结果不能承诺实车节省相同用时。完整对比为 `logs/navigation-terminal-comparison.json`；实车返航后等待的独立重放记录为 `logs/navigation-terminal-field-replay.json`，该重放未证明保留旧观察窗口能缩短本轮等待，因此该项没有部署。
