## 有限修正

- 只在红蓝差分图像中，允许一根略宽灯条，长宽比下限 `max(1.6, 0.8 * min_light_aspect)`；另一根必须符合原严格门槛。
- 略宽灯条还须满足中心偏移≤0.20倍预计灯长、长度误差≤0.30、方向误差≤8°、端点偏移≤0.25倍。
- 两根略宽灯条不能相互证明；原成对角度、长度比及灯间距检查继续执行。
- 灰度强度模式不放宽；仍从实际灯条轮廓提取端点，不用网络角点兜底。
- 严格候选优先，略宽候选额外计1.0分。正式配置下，既有合格严格候选评分上界低于该额外分，不会被新增候选抢占。

未启用此前命中验证回退的亚像素候选，`corner_refine_brightness_invariant_subpixel` 仍false。
