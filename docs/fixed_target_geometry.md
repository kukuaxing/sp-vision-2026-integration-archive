# 固定旋转靶：约17厘米中心距离偏差的定位

## 结论与适用范围

本轮用单独的离线诊断程序复现：实际YOLO与现有角点精修输入下，拟合中心X平均为 **3.168525m**，真实中心为3m，偏差 **+16.8525cm**。主要误差在灯条端点提取阶段已经出现：组合退化图像的灯条长度平均只剩真实投影的92.10%，上下端点沿灯条方向各向内缩约1.96px，PnP因此产生系统距离高估；中心拟合接收这些有偏三维观测，不能自行恢复真实尺度。

这是当前合成图像、相机标定和误差条件下查明的原因，**不是实车距离偏差的测量**。渲染纹理把56mm模型端点定义在完整发光外沿，当前精修则返回较高阈值下的轮廓像素中心，两者物理特征定义不完全一致。现有算法对亮度、模糊、采样尺度的敏感性得到复现，但尚未验证哪种端点定义最符合实物灯条。

没有直接减去17cm、伸长固定2px或修改靶车半径。正式配置、PID、通信、导航和运行二进制保持原样，未启动硬件程序；本轮完成定位和诊断工具，没有宣称已修复实车测距或提高实弹命中率。

## 方法

新增 `simulation/src/fixed_target_geometry_probe.cpp`，编译为 `build/native-offline/bin/fixed_target_geometry_probe`。只读唯一正式配置与权重，使用已有相机投影、纹理渲染、CPU YOLO26、AdaptiveCornerRefiner、Solver、Tracker和FixedCenterModel；不打开相机、串口、导航或电机。

同一固定夹具：中心[3,0,0.03]m，半径0.26/0.28m，角速度+4.56rad/s，50FPS，每条件450帧（9s），渲染种子3011。相机姿态固定朝向靶区，不含闭环云台、姿态偏差和时间戳偏差，以隔离几何来源；因此这不是之前完整发射实验的重跑，也不是命中率测试。

八项对照分别为理想角点、清晰图像精修、仅降亮度、仅曝光、仅模糊、组合退化精修、清晰实际YOLO、组合退化实际YOLO。精修对照用真值端点作为ROI的初始提示，明确属于诊断消融；实际YOLO组没有补真值检测，按正式图像入口执行BGR→RGB并强制全画面检测。

位姿统计限制在相机可见55°内、完整入画的匹配板；实际YOLO返回的大斜角检测仍按原逻辑进入Tracker，未用真值替算法选观测。因此位姿均值、Tracker实际选择的观测均值和最终中心偏差不应混为同一量。

## 逐段结果

| 输入条件 | 单板X平均误差 | 中心X平均误差 |
| --- | ---: | ---: |
| 理想投影角点 | 约0 | 约0 |
| 清晰图像，只精修 | +6.20cm | +6.00cm |
| 仅亮度降至0.65 | +9.88cm | +10.84cm |
| 仅6ms曝光、5次积分 | +7.72cm | +8.36cm |
| 仅高斯模糊σ0.6px | +6.85cm | +7.24cm |
| 精修组合退化 | +13.56cm | +14.38cm |
| 实际YOLO，清晰图像 | +8.70cm | +10.30cm |
| 实际YOLO，组合退化 | +13.53cm | **+16.85cm** |

组合退化另外含亮度0.65、像素噪声σ2。其实际YOLO组：

- 55°内494条匹配位姿，平均灯条长度比0.9209825，灯条间距比1.0001013；主要是长度收缩，横向间距没有同等比例缩短。
- 上下端点各向内缩的平均值1.95999px，端点RMS及完整分布见分析JSON。
- 原始PnP重投影RMS平均仅0.2188px，但单板距离平均高估13.53cm；低像素残差不能证明尺度准确。
- Tracker实际选入的匹配观测545条（含大斜角），单板X平均误差15.94cm，最终中心平均偏差16.85cm。观测筛选和非线性拟合使中心偏差不等于55°内单板平均值。

## 因果消融：长度还是中心位置

独立Python/OpenCV重新执行IPPE，逐条核对C++三维结果，所有条件重算差异均小于0.1mm。以下消融只用于事后分析，使用真值端点长度，**不是可上车的校正算法**。

对组合退化实际YOLO组同一批494组角点：

| 改动 | 单板X平均误差 |
| --- | ---: |
| 完全保留测得角点 | +13.5349cm |
| 只恢复真实灯条长度，保留测得中心和方向 | **+0.0931cm（约0.93mm）** |
| 只恢复真实灯条中心，保留测得长度和方向 | +13.5628cm |
| 全部恢复理想角点 | 约0 |

因此在该组里，长度收缩足以解释绝大部分单板深度偏差，不能归结为装甲板整体中心像素偏移。清晰YOLO组恢复长度后仍有约1.30cm平均误差，说明清晰纹理还存在其他端点/间距误差，不能把单一修正视为所有图像的通解。

另增加完全隔离的真值影子模型：保留实际Tracker的关联面编号、初值、时间戳及重建状态，仅把影子模型的三维观测换成对应真实板中心。八组影子模型拟合中心误差均接近浮点精度。它不参与实际模型、预测或发射；这项消融支持误差主要来自上游三维观测，而非中心拟合固定加了17cm。

关联编号的全局偏移在同一track_id内保持一致；组合退化两组早期因重建切换track_id，编号偏移随之改变，未发现稳定跟踪期间错误交错换面。不能仅因内部面编号与物理编号不相等就判定关联错误。

## 代码对应关系

`tasks/auto_aim/adaptive_corner_refiner.cpp` 的 `refine_light()`：

1. 对红蓝色差图做3×3高斯模糊。
2. 阈值使用 `0.65 * otsu + 0.35 * binary_threshold`，且限制为25—230；本配置binary_threshold为100。它并非完全随灯条亮度同比缩放。
3. `findContours()` 返回整数像素轮廓；对轮廓拟合轴线，再取轮廓点沿轴的最小/最大投影作为端点。

这得到的是当前阈值下的轮廓像素中心极值，未估计亚像素边界，也未确保对应模型中的完整56mm发光长度。变暗和模糊会使有效轮廓端点继续向内移动。

`tasks/auto_aim/solver.cpp` 的 `solve()` 先用四个端点做自由姿态IPPE，得到三维平移；随后 `optimize_yaw()` 采用固定15°模型只优化yaw，**不会重新估计已经有偏的三维平移**。当前流程可以让缩短端点的模型获得很小重投影误差，随后将偏远的三维观测交给Tracker和固定中心拟合。

独立世界投影角点输入下，原相机/世界坐标变换及PnP返回正确公制位置；未发现这组仿真存在外参重复平移、米/毫米混用或把相机距离当成旋转中心距离的固定加量错误。此结论针对当前复现，不能作为真实手眼标定已正确的证明。

## 修正方向与边界

优先统一端点的物理定义，再比较新的端点提取方法。应使用真实装甲板在已知距离、多旋向/斜角、曝光/亮度下采集的图像，确认56mm对应哪个可见发光边界；仿真须保持相同定义。现有外沿、白色内芯、色差轮廓阈值可能对应不同长度，不能用仿真真值替代实物标定。

可验证的实现方向是沿灯条轴建立连续光强/色差剖面，进行亚像素边缘或带模糊的有限长度模型拟合，并给端点和深度附带质量/不确定度。需要检验过曝、暗光、彩色边框、反光和遮挡，不能仅把阈值降低或固定增加像素就宣称解决。

对于安装倾角确已标定的板，可另比较受约束的平移与yaw联合重投影拟合；必须保留倾角不适用的目标分支，避免把假定15°强加给所有真实装甲板。当前仅优化yaw的过程不足以回收先前的尺度偏差。

暂不改开火延时、固定yaw偏置或PID来掩盖此问题。也不通过更改仿真纹理/真实靶尺寸，让旧算法看起来恢复正确；新端点方案必须在冻结的退化条件和全新测试数据上验证几何与命中率。
