# 固定倾角下的平移／朝向联合拟合对照

本轮结论：**暂不替换正式位姿求解器。** 联合拟合在理想角点下能精确还原位姿，在独立像素噪声下有小幅改善；但遇到现有端点缩短和倾角不符时，较低的重投影误差仍可能伴随更大的真实距离误差。它没有解决已经定位的角点定义偏差。

这是文件级几何诊断，没有运行机器人、重建正式程序或改变YAML、PID、通信、导航。没有新增发射，以下不是命中率。历史渲染／YOLO角点已经用于此前调查，本轮明确重用作诊断，不称独立留出。

## 为什么做这个实验

正式 `Solver::solve` 用IPPE同时求平移和自由姿态，随后固定平移，仅搜索普通小装甲板倾角为+15°时的yaw。最终位置仍来自原IPPE，最终朝向来自固定倾角搜索，两步的约束不完全相同。

离线原型固定普通小板尺寸135mm×56mm和+15°倾角，同时调整世界坐标下的X、Y、Z和yaw，最小化四角点的像素平方残差。镜头内参、畸变、相机／云台／世界外参均沿用当前工程。它只接收测量角点、标定及IPPE／旧yaw的初值，**不接收靶心、半径、真值位置、未来帧或命中标签**。

采用有限差分雅可比及阻尼最小二乘；从原yaw及±20°三个初值开始，各最多35次迭代。保留现有以云台yaw为中心±70°的范围，拒绝相机后方投影，目标函数不能比原初值更差。没有根据结果再挑拟合参数。这里只验证普通小板的+15°假设，没有扩展到平衡大板、前哨站或任意安装倾角，也没有接入正式跟踪器。

输出的局部yaw噪声尺度假定角点为独立同分布0.25px噪声；它不包含端点系统偏差、倾角误差或执行器误差，不能作为完整置信度。

## 预先固定的受控输入

种子120031；距离2／3／4米，yaw −50／−25／0／25／50°，每个几何条件8次配对噪声，共120条／条件。五条件合计600条，理想条件的8条重复不当作独立样本。各非理想条件用同一抽样像素噪声配对，未扫描噪声或倾角挑选最佳值。

| 条件 | 原流程X方向误差RMSE | 联合拟合X方向误差RMSE | 原／联合yaw误差RMSE |
| --- | ---: | ---: | ---: |
| 理想角点、真实倾角15° | 约0.0013mm | 数值精度内 | 0.02261°／约0° |
| 独立0.25px像素噪声 | 1.514cm | 1.494cm | 0.7013°／0.6544° |
| 灯条长度缩至92%，叠加相同噪声 | 18.377cm | 18.779cm | 4.9910°／5.4472° |
| 真实倾角10°，仍按15°拟合 | 1.560cm | 1.761cm | 1.1868°／0.9916° |
| 真实倾角20°，仍按15°拟合 | 1.467cm | 1.731cm | 0.9687°／0.5458° |

X为此实验世界中的主要前向距离方向；不是旋转中心拟合误差。噪声条件下，正面0°的yaw RMSE仍为1.3178°→1.1795°，相对±50°更难估计；这些只描述本组几何和噪声，不能直接换算成实车预测准确率。

92%条件的固定模型重投影RMS合并指标从1.1752px降至1.1133px，但距离和yaw误差同时增大。错倾角条件也显示，模型可以通过调整位置吸收错误假设。因此不能把“拟合误差下降”独立作为升级验收条件。

## 旧图像角点重放

重用 `logs/fixed-target-geometry.json` 八种条件，选取原求解有效且板相位在±55°内的3,951条测量。旧位置／yaw直接取当时正式C++输出，联合拟合使用同一组角点。原IPPE位置在Python重放与C++记录最大差约3.50e−15m，确认没有换测量、坐标系或原基线。

传统端点组使用真值ROI，仅用于隔离端点误差；YOLO组实际运行网络，但图像仍为合成。不能据此宣布真实机器人偏差也为16cm。全部条件的联合拟合像素目标函数均不劣于初值，多个条件真实误差仍恶化。

Python原型每板平均耗时约2—7.5ms，本轮与CTest并行执行；不是稳定的端到端性能基准，也不能拿它推断C++实现的耗时。没有为了这个未通过几何验收的候选增加正式CPU负载。

## 对改进顺序的影响

联合拟合的可行性已验证，但当前输入偏差下未通过升级条件，停止向正式程序移植这一原型。后续优先处理可测量的角点偏差和尺寸／倾角假设，并把它们与随机像素噪声分别建模；不能只增加优化次数或强行按固定厘米补偿。真实灯条有效长度、安装倾角与独立位置标签未确认前，保留现有求解器。

后续若重新提出候选，应使用新的距离／姿态／曝光与噪声分组验证几何，再做完整真实YOLO闭环及最差轮命中验收。本轮600条受控数据和3,951条历史重放都已查看，不能继续调参后称为最终独立验证。几何改善也仍不等于解决独立逐发出膛随机性。
