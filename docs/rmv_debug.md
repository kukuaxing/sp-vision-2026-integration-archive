当前附加落点修正：26.6m/s复测后，用户确认3m仍高约5cm，配置 `rmv_ballistic_pitch_trim_deg: -0.95`，负值使俯仰目标降低。该修正以弹道使用的等效枪管仰角偏差实现，瞄准、短时中心保持、未来面资格及发射前复核共用同一方向；不是只修改发送角。弹道仍使用实际目标高度和枪口杠杆臂，不另加目标低于P轴的手动补偿。日志识别目标比P轴低约6.7cm、比枪口低约7.0cm。安装外参和紫色GUN LINE仍是原几何；经验修正不证明实际枪管倾角改变。仅弹道路径应用，普通--rmv-follow与标定不应用；弹速与修正均待不同距离复测。

已知轮径D（米）、电机/轮速比i后，估计弹速为 `π D × 6500 / (60 i) × η`，η初值0.8是未实测的传递效率假设；不是测得弹速。可填实际轮径/传动比自动换算，或填明确的 `rmv_projectile_speed_mps` 覆盖值。RPM只有轮子直连电机且没有减速时才等于轮速。旧车85ms出膛延迟保留为试算初值，当前车尚未验证；65–105ms区间与50ms飞行时间不确定度用于资格判断，可能拒绝高速事件，需要用此车证据缩小误差。

预测路径复用 `Target/YawESKF`、`RotationModelManager`、`GyroPhaseScheduler` 和 `GyroFaceSelector`。低/中速预测未来装甲；高速锁定每块装甲过正面的周期，按图像年龄、拨弹/出膛延迟和弹丸飞行时间选择事件。弹道以G→导航四元数、实际枪口随P转动的杠杆臂和真实枪管方向换算为大Y/P关节目标；不调用旧SP负俯仰/经验偏移作为本车安装标定。

日志 `rotation` 含完整11维模型状态（中心/速度/体航向/角速度/两组半径与高度差）、ESKF与整体NIS、模式、相位锁定、面周期、飞行时间、未来装甲、面ID、资格/拒绝原因和事件时刻。可用 `python3 scripts/report_rmv_follow.py <frames.jsonl> --output <report.json>` 汇总。资格计数不等于实际命中；画面中的相机中心也不等于含重力补偿的瞄准位置。
