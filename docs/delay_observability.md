# 延迟均值、随机时序与视觉指标的可观测边界

## 本轮要回答的问题

前两轮机会筛选在普通条件有收益、40ms假设抖动下出现退步。本轮不再换固定阈值，不声称优化出新的命中率；明确重用已有数据作诊断，分开检查物理延迟均值、逐发随机项，以及已有视觉历史究竟能估计什么。

正式程序、YAML、PID、通信、导航均保持原值；只扩展文件仿真的视觉残差诊断和冻结评估器。出膛10/25/40ms标准差仍是**仿真假设**，不是本轮实测。所有真值干预都限制在评估端，没有把未来出膛或命中标签输入预测器。

## 1. 冻结轨迹：改变均值与随机项

扩展 `fixed_target_counterfactual --delay-grid`，保持原下发时刻、出膛射线、弹速与角散布，改变物理出膛延迟：

`new_delay = max(0, original_mean + mean_shift + original_standardized_draw * new_sigma)`

均值平移-20/-10/0/+10/+20ms，标准差0/10/25/40ms，共20格/策略。原标准化抽样从已知仿真记录恢复；若原延迟被截断到0，无法唯一恢复抽样，工具拒绝推算。没有根据好看的格点重新选控制器参数。

输入为上一轮历史间隔主留出1,200条与压力800条；这些已被查看，现只用于诊断。共120格、40,000次冻结弹道评估，**不是40,000发新试验或新控制器表现**。不重新积分相机/跟随或重跑门控；物理均值平移也不等于修改预测器延迟。

### 强抖动组（原均值340ms、标准差40ms，每策略200条）

| 评估端干预 | 旧策略 | 时间余量策略 |
| --- | ---: | ---: |
| 原记录 | 155 | 151 |
| 只将物理均值提前10ms，仍有40ms抖动 | 157 | 159 |
| 保持原均值，只移除逐发延迟随机项 | 193 | 196 |

在所扫的五个均值上，40ms条件最佳格点也仅157/159。**这不能作为实车提前10ms的建议**；它说明这组冻结轨迹里，单改均值的帮助远小于人为移除随机项。193/196是简化物理误差后的诊断分数，不是达到的新命中率。

### 主留出冻结轨迹（每策略600条，均值不变）

| 新的假设标准差 | 旧策略 | 时间余量策略 |
| --- | ---: | ---: |
| 0ms | 591 | 595 |
| 10ms | 588 | 593 |
| 原25ms | 550 | 560 |
| 40ms | 469 | 471 |

后两行不能当作相同控制器在新40ms闭环下的独立检验。原25ms行必须逐条复现原计分；其余行只描述相同射线/序列对时序随机性的条件敏感性。此前小压力组时间余量少中4发，也不能据此断言它在所有高抖动样本中必然更差。

## 2. 视觉相同、出膛不同的孪生对照

使用上一轮已看过的91001、67.5°、双旋向子集，仍经真实YOLO26与现有估计器。两世界只改变独立出膛标准差10→40ms。为排除出膛事件切分数值积分带来的微小相机/伺服耦合，**两边均显式将虚拟伺服改为瞬时响应**。它是可观测性诊断，不是可上车的电机控制或新留出。

当前渲染与输入只有装甲板，没有发射后坐力、弹丸影像、拨弹状态或出膛传感器；真实世界若增加这些观测，结论的适用条件会改变。目标真值只用于生成图像/独立评分，不作为检测结果或预测回退。

| 条件 | 10ms世界 | 40ms世界 |
| --- | ---: | ---: |
| 命中/100 | 98 | 84 |
| 负旋向/50 | 49 | 41 |
| 正旋向/50 | 49 | 43 |
| 全部100次下发时间 | 两世界相同 | 两世界相同 |
| 全部100次视觉残差、预测/命令状态 | 两世界相同 | 两世界相同 |

共同时间前缀的装甲板角点、相机/云台状态、跟踪和视觉质量也相同，只有真值HP不参与比较。14条命中结果发生变化。结论限定为：**当前装甲板观测与现有残差指标无法辨识这项独立的逐发出膛随机误差**；不能由“视觉残差小”推出“弹丸到达时间可靠”。不是说任何相机方案都无法测出膛时间。

直接核对的是共同记录的546个抽帧（每5帧记录一次）和全部100次发令状态，未宣称逐像素保存并核对了所有原始图像。相同输入的构造还依赖同一渲染种子/时钟、瞬时伺服及无发射反馈条件。100次发令的视觉历史误差边界中位数约0.03641°、P95约0.04548°，两个世界数值相同；这些是Yaw视线残差，不能直接与靶车转动角度作数值对比。

新增仿真字段 `visual_residual` 记录偏差、散布、历史误差边界、成熟周期、修正量和配对数，仅增加诊断，不改变原门控。现有 `FacePredictionResidual` 的输入和代码注释原本就限定它比较原始预测与以后同面装甲板观测，不是命中或执行器延迟估计器。其Yaw视线误差也不能未经几何换算直接当成靶车转角误差。

## 3. 可用与不可用的不确定性

视觉历史可检查本身的预测一致性、遮挡/身份切换、几何拟合与时间戳问题；它不能凭空补出独立、未被观测的当前拨弹/出膛随机项。因此暂不把视觉散布包装成“完整到达时间置信度”，也不据此默认启用动态发射窗口。

要标定执行器部分，后续至少要有可配对的发令与实际出膛事件及可说明的同步误差；拨弹命令次数、视觉预测命中时刻、靶板消失时刻均不能直接替代实际出膛标签。完成硬件维修后再采集，当前不会生成假实测或修改实车均值/抖动参数。

为区分时间项，审计另外计算真值模型相位的四分之一转等价误差，以及：

`actual_arrival - model_impact = (actual_delay - true_mean) + (true_mean - nominal330ms) + remaining_flight_and_prediction_timebase`

这是评估端的时间恒等式；最后一项包含飞行、模型时基及几何等影响，不是纯几何误差的独立因果估计。相位四分之一转折叠也不能确认真实板身份，更不能作为在线真值校正。具体分布写入审计JSON，不把这些标签送回估计器。

| 旧策略原记录 | 到达减预测：均值/标准差 | 已假设出膛随机项标准差 | 剩余飞行/时基项：均值/标准差 |
| --- | --- | --- | --- |
| 主留出25ms条件 | +2.979 / 23.547ms | 23.540ms | -7.017 / 1.750ms |
| 压力40ms条件 | +6.163 / 39.705ms | 39.895ms | -7.298 / 1.710ms |

表中是有限、有关联仿真记录的样本内总体标准差，不是实测或置信区间。固定均值差为+10ms；40ms组随机抽样本身平均偏+3.461ms，故其到达均值约为 `10 + 3.461 - 7.298 = 6.163ms`。不能拿6.163ms全部当作固定标定偏差。模型真值相位的四分之一转等价时间误差均值约-5.2至-5.5ms、标准差约1.6至1.9ms，也仅是已知世界的诊断量。

仅作理想水平截面的说明：4.56rad/s下40ms对应约10.45°相位标准差；135mm板宽、0.26—0.28m半径的中心射线半窗口约13.55—14.55°。若只剩独立高斯时序误差、完全居中，简化式 `erf(half_window / (sqrt(2)*omega*sigma))` 给约80.5%—83.6%。它忽略动态求交等因素，不是实际命中率或严格物理上限，只说明固定角度补偿无法消除独立随机尾部。
