# 视觉离线工作：部署后的优先顺序

## 当前可用材料与限制

当前小电脑可读取7MB的 `data/offline-input/test.mp4`、约1.2MB的 `data/field/tracker_observations.json`、68张 `data/calibration/sentry_handeye/*.jpg` 和历史 `logs/diagnostics/vision-*.jsonl`，并已具备渲染、实际YOLO、几何/跟踪/预测和独立弹道计分入口。

旧跟踪记录只有检测角点与姿态，不能从中重新比较端点提取算法；旧实测图像/视频可比较提取成功率与观测一致性，但没有独立测距和出膛标签时，不能称测距准确率或命中率。68张标定照片也不自动等于手眼标定已通过，需核对每张姿态来源、同步和实际安装。

抽取现有一份实车诊断记录进行新分析工具兼容检查：882帧，其中734帧有有效主观测，灯条长度中位数约46.09px。记录未包含独立真实位置与新增身份字段，因此没有报告真实距离偏差；不能由这批旧数据确认实车也偏17cm。

本轮还实际分析了旧 `tracker_observations.json` 的2,168帧、43.615s观测节奏：有效平均49.685Hz，中位间隔20.003ms，P95约26.751ms，P99约26.820ms，最大66.594ms；无乱序，超过40ms一次，超过100ms零次。这是历史处理后观测节奏，不能当作当前相机上限或采集/推理延迟。可把这组非均匀间隔作为后续仿真采样扰动，取代永远精确50FPS的假设。

建议顺序是完成本轮部署和验证，再做P0的时序/失效压力矩阵，随后扩展距离、转速和显式平移。不要在当前少量种子上反复挑到好看的参数，也不要让固定中心模型套用于明确平移的目标。

P0分离消融已完成首轮，详见 [端点/随动/时序对照](endpoint_ablation.md)。旧留出子集明确重用为开发数据：固定相机、瞬时跟随和冻结射线消除跟随误差均未改变92/100与89/100的差别；完整旧/新600发冻结预算中，把假设的随机出膛时间固定为原均值后变为587/600与586/600。当前更应验证时序分布和发射机会选择；25ms仍是假设，不作为真实机械诊断或上车补偿。

后续发射机会筛选已完成完整闭环新分组验证，见 [中心机会实验](centered_opportunities.md)。开发阶段预先比较3°/6°，冻结6°后不再选参。新留出568→573/600，但最差88%→86%，40ms假设抖动压力86→85/100，未通过预定稳健性门槛，不部署；全部轮次仍满足完整50发预算与60秒射击观察窗。1,900条新实验独立求交、100条默认历史兼容重放及54项回归通过。下一优先级为真实非均匀观测节奏、更多独立种子的机会/时间余量验证和实物时序分布标定；不要在本轮已查看数据上继续选参自证。

历史非均匀节奏与时间余量验证也已完成，见 [历史间隔实验](recorded_cadence.md)。严格累计2,167个旧观测间隔，忙时丢弃、不平移采集时间；处理帧编号已与正式入口对齐。固定20ms横向余量在六个新种子留出中550→560/600、最差82%→84%，但40ms假设抖动压力155→151/200、最差70%→68%，整体不采用、不部署。2,400条新发射、61,702条采样事件、估计余量和100条默认兼容重放审计通过，54项回归通过。下一离线方向应分离预测相位/延迟均值偏差与逐发随机时序，说明不确定性的可观测来源；不继续只换固定阈值。本轮组已全部查看，后续只能用作开发/诊断。

均值/随机项与可观测性分离诊断已完成，见 [时序观测边界](delay_observability.md)。旧强抖动轨迹保持40ms、只提前物理均值10ms为157/159（原155/151），保持均值仅移除随机项为193/196；均属冻结评估，不能作为新算法或参数建议。瞬时伺服孪生中546条共同抽帧和100次发令/视觉残差相同，命中98→84/100，证实当前装甲板输入不包含独立出膛随机项。后续不要由视觉残差直接推完整到达时序置信度；优先准备可配对的真实发令/出膛标签及同步误差说明，视觉与执行器不确定性分别建模。120格/40,000次独立复算、100条有限伺服兼容记录与54项回归通过；未部署新策略。

受约束联合拟合首轮也已完成，见 [联合几何对照](joint_pose_geometry.md)。600条受控输入与3,951条历史角点重放中，独立像素噪声的X误差RMSE仅1.514→1.494cm，而短端点18.377→18.779cm、真实YOLO退化16.189→16.558cm；错倾角也可使位置恶化。全部候选像素目标不增，仍不保证真实几何更准，因此不移植、不修改正式求解器。4,551条独立投影复算、7项新增测试、54项原回归通过。下一步优先修正可观测的角点模型与倾角／尺寸假设，避免仅增加优化复杂度。

端点光度／外观首轮已完成，见 [光度对照](lightbar_photometry.md)。固定几何的渐变圆头／均匀圆头／均匀平头、亮度、曝光、模糊和双旋向共1,080张图。共同有效样本上，旧候选X误差RMSE分别14.066→3.512、5.013→2.221、2.723→3.976cm，平头反例不支持通用启用。新增实拍事件剖面工具，16帧13个未独立标注检测中26根灯条有10根轴线峰值低于诊断阈值，两阈值方法均如此；它不是测距准确率或现场根因确认。2,152条位置独立复算、72张默认兼容、7项新测试及54项原回归通过。下一候选需定义物理端点并覆盖外观变化，再做新组闭环；不要继续只调单一纹理的阈值。

时序组合链首轮已完成，见 [时序故障矩阵](timing_pipeline.md)。显式仿真每5ms IMU采样／到达与真实PoseHistory查询，参考改变仅在新包到达后对主机生效。18项关键点和5项真实YOLO图像、双旋向共46轮，72,201条事件／2,300条弹道独立核对；8次已合格后故障、8次参考重建、16帧非单调观测检查通过，未发现重复物理经过发令。55项回归及100条旧默认轨迹通过。固定内部30ms／运输25ms延迟的动态负对照仍可能通过时效查询，不能当已解决硬件同步；正式程序不变。下一工作可区分重放帧与真正时钟改变，评估重新积累质量历史的时间代价，并继续补完整standard／串口／任务故障覆盖。

异常恢复的精确旧帧候选也完成首轮，见 [旧帧准入与恢复对照](frame_admission.md)。只跳过参考一致、100ms内已见过的帧号／时间精确对，新图像配错误时间仍走原异常处理。新图像留出真正重放组结束时间45.488→24.488秒，但各少中1／100；700条负对照／正常控制一致，56项回归及2,800条弹道复核通过。252份旧日志778,364条有效帧号记录没有同类重放证据，不能把仿真收益直接套到现场。候选不接入正式循环，降低本分支优先级；下一重点为端点正交拆分与实拍几何／光度，出现现场重放证据后再补串口心跳和完整任务／模式覆盖。

## 已准备的实车数据分析入口

正式日志新增灯条长度/间距、云台坐标位置、原始yaw与固定模型重投影误差，以及每条记录的构建源指纹、运行配置指纹和端点算法名称。只在原有已启用、限量和抽帧的诊断路径计算/写入，不增加无界存盘。

读旧/新日志，不指定真值时只报告分布：

```bash
python3 tools/analyze_geometry_capture.py logs/diagnostics/vision-实际文件名.jsonl \
  --output logs/geometry-capture-analysis.json
```

固定云台，对单块静止板做过独立位置测量后，可显式传入 **云台坐标系中的板中心X/Y/Z，单位米**：

```bash
python3 tools/analyze_geometry_capture.py logs/diagnostics/vision-实际文件名.jsonl \
  --expected-position-gimbal 3.0 0.0 0.03 --output logs/geometry-capture-analysis.json
```

命令中的坐标只是格式示例，必须替换为测量值。不能把旋转中心位置当作当前板中心，也不能拿相机光心测得距离直接当云台坐标位置。工具按构建/配置/端点算法分组；旧日志缺少云台位置时不会猜造距离准确率。

## 暂时不能靠离线证明的项目

完整指令至出膛延迟、摩擦轮弹速稳定性、拨弹机械行为、真实PID和电气问题、真实手眼标定及裁判命中计分仍须现场验证。仿真0/+20ms、-0.12°和17cm都不作为实车固定修正；诊断影子模型的真值输入只用于定位原因，不能进入控制器。
