# 灯条端点：阈值、截面和运动模糊的分离对照

本轮进一步定位了几何偏差的来源：**端点误差依赖灯条的颜色／亮度截面和端帽形状，不能简化为固定缩短几个像素。** 旧Otsu＋亚像素候选在原渐变圆头合成灯条上改善明显，在均匀平头灯条上却产生外扩并使距离误差变大。因此继续保持候选关闭，没有改正式求解器或增加实车补偿。

本轮只做几何／光度诊断，没有新命中率或发射验证。输入为仿真图像和已经解码保存的旧实拍录像；未打开相机、串口、导航或真实控制程序。

## 1. 需要分开的两个问题

当前提取器使用 `abs(B−R)`，可消除RGB／BGR通道顺序差别、抑制白色数字和面板；代价是接近白色的灯条亮芯也会变弱。默认程序化纹理的外层、中层、亮芯颜色差值分别约105、225、35，且端帽均为圆头。这是人为测试外观，**没有被实拍标定证明是实际灯条的发光截面**。

旧阈值为 `clamp(0.65×Otsu + 0.35×100, 25, 230)`。在线性、未截断区间，若亮度缩为b，则相对于亮度归一化的常数部分为35/b；图像变暗时，它不会等比例下降。整数轮廓端点还受像素量化、圆头形状和滤波影响。

已有候选同时改成纯Otsu和亚像素等值线边界。它减少了绝对阈值的亮度依赖，但某个等值线未必就是几何标签定义的端点。两项改动仍绑定在原开关中，本轮没有声称已分别量出它们各自的净收益。

## 2. 受控图像矩阵

保留默认外观，增加两个仅供仿真的 `lamp_style`：

- `original`：原来的渐变圆头、近白亮芯，默认行为不变。
- `uniform_round`：均匀颜色圆头，与原灯条使用相同外宽和端点跨度。
- `uniform_flat`：同色平头矩形，使用像素面积覆盖，使几何标签处为半覆盖边界。

三种外观共享160个纹理像素的端点跨度、30像素外宽、135mm灯条间距、56mm灯条长度、相同相机／外参及靶车几何。仅改变外观，不改变几何标签或直接把真值塞入求解器。

首轮探查发现，直接使用整数闭区间绘制平头矩形，会额外引入半个源像素的边界跨度。因此改为标注边界处半面积覆盖，并完整重跑矩阵；下表和最终JSON均来自修正后结果。首轮探查数字不作为正式结论。

预先固定2／3／4米，−45／−20／0／20／45°，转速±4.56rad/s，亮度0.55／1／1.45，曝光0／6ms，镜头模糊0／0.6px。曝光使用5个对称采样，时间中点不变。共1,080张图，每图同时检查正式旧提取和已关闭的候选，共2,160次提取；无传感噪声、未扫阈值挑最佳值。种子130003只保留可复现入口，不将确定性重复算作新随机试验。

**提取ROI由真值端点提供，只为隔离提取器。没有YOLO检测、跟踪、发射门控或弹道闭环。** 位置由真实C++提取器／正式Solver计算，真值只用于ROI诊断和评分。故本轮不能替代此前真实YOLO命中留出，也不能据此启用候选。

## 3. 几何结果与失败数量

| 外观，每种360张 | 旧路径有效／360 | 候选有效／360 | 共同有效样本的X误差RMSE：旧→候选 |
| --- | ---: | ---: | ---: |
| 原渐变圆头 | 352 | 360 | 14.066→3.512cm，352对 |
| 均匀圆头 | 360 | 360 | 5.013→2.221cm，360对 |
| 均匀平头，边界修正后 | 360 | 360 | 2.723→3.976cm，360对 |

原外观8张旧提取失败、候选恢复；其他条件无提取或位姿失败。没有把失败样本按零误差计入，也没有只比较不同成功集合后宣称收益。包含候选全部360张时，原外观候选RMSE为3.488cm，与共同352对的3.512cm应区分。

全部有效样本的平均灯条长度比例分别为：

| 外观 | 旧路径 | 候选 |
| --- | ---: | ---: |
| 原渐变圆头 | 94.852% | 99.325% |
| 均匀圆头 | 98.639% | 100.248% |
| 均匀平头 | 99.632% | 101.035% |

原外观中阈值高于轴线峰值的灯条为旧276／720、候选192／720；均匀颜色的两种外观均为0。这说明颜色／亮度截面的确会改变提取行为，但“移除多层外观”同时改变了颜色截面和亮芯，不能只归因于其中一个因素。

仅取无曝光积分、无镜头模糊的原外观，亮度0.55／1／1.45下，旧路径X误差RMSE约12.197／8.294／11.412cm；候选约3.623／3.715／4.775cm。1.45倍亮度包含8位通道截断，不能期望严格线性。偏差在没有运动模糊时也存在，故不能全部归咎于曝光拖影。

有无6ms曝光的原外观旧路径RMSE约10.903／16.532cm；候选约3.956／2.947cm。后者并非“模糊必然改善”：这是该合成截面、采样和阈值的交互，其他外观结果不同。切勿用单一曝光条件挑候选。

双旋向共1,080对提取结果，成功／失败状态一致，角点最大差约0.000366px。由于无噪声、曝光对称，只是倒置采样顺序，**它们不是独立试验，也不是双旋向命中证明**。本轮没有发现这一对称光度构造本身产生旋向差别。

## 4. 旧实拍录像的适用性检查

新增 `tools/analyze_lightbar_photometry.py`，读取现有标准事件记录与对应图像，核验图像SHA256和尺寸，对已输出角点附近的红蓝差值进行剖面检查。它不运行网络、不打开设备，也不重新求三维位置。

```bash
python3 tools/analyze_lightbar_photometry.py \
  data/replay/endpoint-baseline/events.jsonl \
  --output logs/photometry-recorded.json
```

现有16帧、13个检测结果、26根灯条全部读入，无边界跳过；10根的轴线峰值低于旧诊断阈值，候选诊断阈值下也是10根。这与低对比度／轴线空心现象相符，说明仅降低阈值未必解决所有样本。

但这些是**未独立标注的检测结果**，可能含误检；ROI来自已经输出的角点，不是当时网络初值ROI，因此诊断阈值不能当作原提取内部阈值的精确重建。小样本没有真实端点、位置或出膛标签，不能确认白芯是实际失效根因，也不能从中报告真实测距或命中准确率。

## 6. 改进决策

这轮把“调阈值”升级为可重复的外观鲁棒性检查，补上了原单一圆头纹理容易遗漏的平头反例。保持原候选关闭；不按平均误差统一伸长灯条，也不根据这轮结果换一个Otsu系数。之后的候选须明确端点对应的物理边界，分别覆盖亮芯、渐变、圆头／平头、饱和、距离及曝光，报告缺失与共同有效样本，之后再进入真实YOLO、完整50发预算和新种子闭环验收。

真正缩小仿真与实车差距，需要补真实灯条截面／曝光和独立端点或板位置标签；现有日志工具已经能先收集并分析光度剖面。不能把这轮合成几何改善称为已经提升实车命中率，也不能将它代替独立出膛时间观测。
