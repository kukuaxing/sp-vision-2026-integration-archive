# 底盘导航转向接口

2026-10-23：接通现有NAV V2 `wz` 字段，不增加报文或改变平移轴映射。烧录与读回状态见 `logs/sentinel-v2-validation.json`，不能用本说明代替读回记录。

- `vx`、`vy`仍为原始控制幅值，增益159、原平移限幅与平滑不变。
- `wz`也采用原始幅值：目标旋转混合量为 `159*wz` motor rpm，单独限制为±200 motor rpm。它不是已经标定的rad/s。
- 每个5 ms控制周期最多改变10 motor rpm；正负切换经过平滑。
- 正 `wz` 对四轮混控均加入正旋转分量。相对于实车左转还是右转，仍须现场验证，未验证前上位机保持 `wz=0`。
- 全零有效NAV使转向平滑归零；显式撤销、租期到期和退出AUTO清除NAV转向平滑状态，后续接管从零开始。
- 原遥控接管规则保留：没有有效NAV且遥控在线时，使用当周期遥控指令；遥控失联和STOP清底盘输出。NAV过期不能被当成已经确认实物停车。
- 上位机给平移／转向速度目标，下位机继续负责电机控制。后续航向保持用定位朝向误差生成有界 `wz`，不直接输出电流。

仅修改 `RC::OnPC` 的导航状态清理、`RC::ApplyNav`、`RC::StopChassis`、RC导航平滑成员和接口注释。没有修改自瞄、云台、发射控制函数。

四个原固件测试变体均编译并运行真实NAV解析器与 `ApplyNav`，覆盖限幅、正负平滑、平移保持、NaN/Inf拒绝、零指令、撤销、租期、模式退出和遥控失联。离线通过不代表实际转向符号或闭环已经验收。

固件更新后，旧导航源码证明与启动身份会失效。上位机必须核对新固件和新boot后重新准备入口，不能沿用旧动作许可。
