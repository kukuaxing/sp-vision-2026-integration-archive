# 历史非均匀观测节奏与横向时间余量

本轮完成：补入历史间隔采样与忙时丢帧，修正仿真处理帧编号，使其与正式入口一致。预先固定的20ms横向余量在新留出中 **550→560/600，最差82%→84%**；但40ms假设出膛抖动压力 **155→151/200，最差70%→68%**。按预定门槛不采用、不部署，正式程序和配置保持原值。完整54项回归、2,400条新实验独立弹道复算、采样/余量与默认100条历史重放审计通过。

## 先明确数据边界

输入是 `data/field/tracker_observations.json` 的2,168条历史处理后观测时间，2,167个间隔，持续43.614784s；平均49.685Hz，间隔范围约13.010—66.594ms。原始文件SHA为 `0b06b95ff469d9e2e287098f7359f692ed3f6279b574a8db8f0f22ee2f491da4`。

本轮**只用这些间隔生成仿真采样时钟**，不重放其中的角点/IMU、不把它当作真实曝光中点、采集帧龄或出膛延迟测量。处理年龄仍保留此前8.36ms均值与4ms标准差的假设；随机5%缺帧、实际YOLO26、有限云台、物理出膛/弹速/角散布均保留。历史间隔与这组假设的组合是敏感性测试，不能说精确重建了当时机器人。

## 时钟与忙时丢帧

默认均匀模式沿用 `frame/fps` 的原有精确算式，兼容原实验。指定 `sampling.capture_intervals_s` 后，严格逐项累计间隔，以 `seed % 2167` 为起始位置，超过原序列则循环接续；不同旋向使用同一采样序列。不同起点不等于新的独立实测记录。

处理尚未结束时到达的采样被明确丢弃并记录为 `busy_drop`，不平移该帧采集时间、不累计无界队列。随机缺帧与忙时丢帧分开；忙时丢帧不会伪造预测观测或发射许可。模型时间戳来自实际使用的仿真采样时刻，加原已声明的时间戳偏差。每次采样及忙时丢弃、逐发采集/决策/下一采样时间均写入离线记录供独立复算。

这代表一种无排队、忙时丢帧的仿真处理模型，不证明真实采集线程采用同样策略。本轮所有新策略都即时下发，不跨帧持有未来许可；旧亚帧实验的下一采样边界改为当前真实仿真时钟，旧均匀输入结果应逐字段复现。

核对正式入口 `src/standard.cpp` 后，已处理帧编号独立于采样时钟索引：忙时丢弃不跳过处理序号，匹配 `vision_frame_sequence` 的正式调用；时间间隔及缺少观测仍由原有时间/质量门槛处理。最初试跑曾错误地让忙时丢帧造成编号跳跃，发现后停止、清理本轮临时文件并重跑全部实验；那些中间数值作废，不能纳入最终结果。审计逐发检查处理序号与接受的采样事件一致。

## 固定候选：估计横向时间余量≥20ms

候选在新数据运行前固定，不从本轮命中标签拟合参数：

1. 使用两个**估计**半径中较大值、**估计**中心距离、预测相位及当前虚拟编码器相对估计中心的Yaw误差。
2. 板宽沿用控制器的135mm几何假设，另固定预留0.2°角误差；二者不从当前物理真值或弹着点读取。
3. 横向剩余长度 `usable = 0.135/2 - estimated_range * (abs(tan(tracking_error)) + tan(0.2°))`。
4. 估计相位容限 `capacity = atan(usable / max(estimated_radii))`；剩余时间 `headroom = (capacity - abs(predicted_phase)) / abs(estimated_omega)`。
5. 只有原全部门槛成立且 `headroom >= 0.020s` 才允许发令；无效估计、余量非正均不产生新资格。默认0关闭该筛选，原路径保持原值。

这是横向小几何近似和工程余量，**不是命中概率保证**，不替代原俯仰、质量、限频、连续观测和同面去重。20ms、0.2°是预先声明的控制器假设，物理端仍分别测试25ms及10/40ms出膛标准差，没有读取当发真实延迟来挑时机。

## 验证与保留结论

完整54/54 CTest通过，94.95s；新时钟与余量单元覆盖均匀精确算式、非均匀累积/循环起点、非法间隔、旋向对称、半径顺序、跟踪误差预留与无效几何。关闭新功能后，当前仿真逐字段复现历史100发，数值差异<1e-9；仅计兼容检查，不算新验证。

独立审计 `logs/recorded-cadence-audit.json` 对开发400、留出1,200、压力800条记录，合计48轮/2,400条新发射逐条重做NumPy连续求交；核对61,702条采样事件、996次忙时丢弃（跨策略累计，不是独立真实事件）、处理序号、估计余量、计分、50发分母、因果时间与同序号物理随机扰动。各阶段数据/源码/配置/模型/仿真指纹匹配。默认重放结果带当前指纹，最终审计只复用本轮一致的证据，不重复执行或改写历史报告。

正式YAML SHA仍 `e087e02c2c6ad257acef5a0808950a42f15445c4ed00714807023dad7427fd90`，正式二进制仍 `dbc3d740d18255383af4f211b9bb8b740bbee0c65d31b0d18c8a757f378d5cfe`，新端点开关仍false。未启动真实相机、串口、导航或发射；处理帧计数修复只针对本轮新增仿真，正式入口原本已按处理帧计数。

保留的工程结论：后续仿真应纳入非均匀间隔并保留原始采样时间，不能用忙时推迟采集或额外编号跳跃替代真实时钟；20ms固定余量在部分条件改善横向脱靶，尚不能保证较强时序不确定性下的收益。继续离线工作时应分离预测相位/延迟均值偏差与逐发随机时序误差，避免只换相位阈值；若做动态余量，必须说明其不确定性来自哪些可观测历史量，不能把当发未来延迟喂给控制器。本轮各组已被查看，后续均作为开发/诊断，新的最终验证需再划分数据。
