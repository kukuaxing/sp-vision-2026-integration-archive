# 固定旋转靶：脱靶归因与离线时序标定

目标是在保持300血、50发预算及中等物理误差分布的情况下提高命中率。上一轮独立YOLO图像留出组从531/600（88.50%）提高到552/600（92.00%），最差一轮80%提高到88%，两旋向均6/6完成。统一+20ms未通过图像复核，选用分旋向的离线标定；继续优化见第9节，前轮结果与失败过程保留。本轮新增俯仰标定未通过新留出组：573/600变为572/600，不采用，仍保留上一轮方案。

只修改离线入口的实验控制器，不改正式 `configs/standard.yaml`、模型权重、硬件通信、PID或导航；没有启动真实机器人。当前结果表示合成条件下的几何命中，不能作为实车命中率。

## 1. 先判断丢在哪里

对前轮真实YOLO联合仿真的61发脱靶，用独立的弹丸—运动板平面求交程序离线重算，取最接近有效矩形的正向穿面位置：55发仅越过左右边界，6发仅越过上下边界。两个旋向分别19发与42发脱靶，其中横向16与39发。已有命中结果与独立求交核对一致。

分析使用 `simulation/analyze_fixed_target_misses.py`，输出 `logs/fixed-target-miss-analysis.json`。这是事后评估，使用真值解释脱靶；运行中的控制器不导入这个程序、不读取碰撞位置或未来出膛时间，也不从模拟HP学习。

## 2. 检验并保留负面结果

先测试帧内过中线定时：根据当前预测相位和角速度求 `wait=-phase/omega`，只允许非负、短于下一次采样的等待；所有原观测、身份、质量、俯仰、两帧证据、射频和每面去重条件继续保留。不能把下发回填到过去，也不能跨过下一帧持有许可。

在开发组角点输入下，原逻辑520/600（86.667%），帧内定时521/600（86.833%）；最差轮次由76%变为74%。这点波动不足以支持采用它，最终选择仍使用原帧级下发。短时定时原型只留在仿真实验及边界测试里。

## 3. 离线预测时间标定

当前正式预测延迟为330ms，中等物理场景假设真实出膛均值340ms，还含5ms时间戳偏差、25ms出膛抖动、50FPS离散采样、姿态及枪口偏差。它们并非都能通过视觉自检辨识。尤其不能将视觉未来观测残差当成已测得的真实出膛延迟。

新实验字段 `controller.prediction_time_offset_s` 仅改变预测副本的未来时间参考，范围限于±50ms；不改物理延迟、不改变随机弹速或弹丸散布。正式Aimer仍读取330ms，实验报告单独记录额外补偿，避免把参数变化藏起来。

用种子27/83/149、初相位0°/45°、两旋向作开发组，事先指定0/5/10/15/20/25/30ms候选，不在测试组上继续调参：

| 额外预测补偿 | 命中/预算 | 最差一轮 |
| --- | --- | --- |
| 0ms，原逻辑 | 520/600，86.667% | 76% |
| +5ms | 528/600，88.000% | 80% |
| +10ms | 540/600，90.000% | 82% |
| +15ms | 552/600，92.000% | 86% |
| **+20ms，开发组选定** | **559/600，93.167%** | **90%** |
| +25ms | 554/600，92.333% | 86% |
| +30ms | 546/600，91.000% | 84% |

选择后冻结为+20ms，帧内定时关闭。这个数是对当前合成条件的离线综合补偿，**不等于实测出膛延迟，也不应直接改实车为350ms**。真实设备还需用独立录像/出膛观测完成标定。

## 9. 继续：俯仰标定、较小半径选面和正式残差路径

### 9.1 诊断与边界

前轮改进组48次脱靶为39次纯横向、9次纯纵向。两个旋向的横向平均穿面偏差约-1.3/+1.8mm，已接近对称；纵向平均偏高约5.1mm，9次纵向脱靶都越过上边缘。中心平面位置估计误差均值约16.8cm，主要表现为距离方向偏差，仍未修复；本轮没有把真实中心距离直接写回估计器。

控制器继续使用上一轮冻结的分旋向0/+20ms，不重新选择时序参数。所有正式YAML、权重、PID、通信和导航保持原值。新增选项仅在离线控制器中比较，目标运动、物理误差、命中窗口、50发预算和60秒射击观察窗均不改。

### 9.2 俯仰标定是离线落点标定

仅用第一阶段旧开发数据（211/397/619，90°/135°）原分支的600条带标签弹道，离线重算穿面高度。按每条弹道的传播距离与15°板倾角换成小角度误差，取中位数0.113399°，按预定0.02°粒度取整得到 **-0.12°**，界限±0.3°。不是从最终新测试组反推参数，也不是纯视觉在线测到了真实枪口偏差。

字段 `controller.elevation_trim_deg` 只改变虚拟俯仰命令，保留物理端原有枪口偏差和散布。角度经有限云台响应后才在实际模拟出膛时取样；没有直接移动弹着点。实车必须另做独立落点标定，不能直接复制-0.12°。

### 9.3 小半径选面没有足够收益

按拟合的两组半径选择较小半径对应的板，半径差≤3mm时保留两组；无效几何关闭该选面资格。分支只读取估计半径与模型面编号，不读取真实半径/真实面身份。

角点开发组12轮的对照：

| 策略 | 命中/预算 | 最差一轮 | 最慢第30次命中 |
| --- | --- | --- | --- |
| 既有分旋向时序 | 564/600，94.0% | 88% | 20.492s |
| 仅加俯仰标定 | 567/600，94.5% | 88% | 20.492s |
| 俯仰标定+小半径选面 | 567/600，94.5% | 86% | 36.363s |

小半径方案没有比单独俯仰标定多中，最差值还下降，完成时间延长，因此不进入最终候选。它保留为明确的负面实验，没有修改靶车真实半径来提高分数。

### 9.4 补上正式程序已有的历史视觉校正对照

对照 `src/standard.cpp`，正式程序把 `FacePredictionResidual::correction_rad` 加入预测yaw，并在残差模型变化时重建过面窗口证据；旧仿真只运行残差监测，未应用这一校正。新增 `controller.apply_visual_residual_correction` 复现这条调用顺序：先记录原始预测，使用已完成同面观测与历史周期得到的有限校正，再更新发射窗口。没有拿未来真值、真实命中或当前弹着点学习。

这是仿真调用一致性补充，正式程序原本已有此功能，本轮未修改正式程序。对照选项默认保留旧行为，便于与历史基线比较；显式启用才应用校正。它仍不等于完整主入口、真实IMU/串口或真实俯仰像素残差链。

独立NumPy求交复算全部1,200发，命中与C++逐发一致。既有策略27次脱靶为23次纯横向、4次纯纵向；新方案28次为24次纯横向、3次纯纵向、1次双向越界。平均穿面纵向偏差由+5.169mm变为-0.682mm，证明俯仰命令对落点确实有效，但均值居中不等于命中率提高。600组成对发射中74组下发时刻发生变化，最大约0.714s；相机跟随、观测拟合与触发构成闭环，不能将结果解释成单纯平移落点，尚未通过消融确认具体原因。

本轮中心估计误差均值约16.7—16.8cm，仍以距离偏差为主。这是当前仿真发现的未解问题，不是对实车误差的测量；没有确认外参重复平移或关联索引错误，也没有用真实中心修正控制器。后续应优先检查投影端点、PnP及角度相关距离估计，避免继续堆固定补偿。

图像实验结束后完整54/54 CTest通过，耗时141.27s。三份当前源码严格审计通过：角点开发36轮/1,800发（含基线确定性重跑）、图像开发12轮/600发、最终24轮/1,200发。核对计分、因果时间、成对随机物理扰动、开发/测试分离及冻结策略、源码/权重/配置指纹，正式二进制身份保持不变且未执行。审计文件为 `logs/fixed-target-selective-*-validation.json`。

三份HTML逐候选、逐旋向验证切换、时间轴、播放/暂停/复位及0/20ms显示，桌面和窄屏均通过，无脚本错误或外部请求；检查记录为 `logs/fixed-target-selective-*-report-qa.json`。原始物理难度、板尺寸、50发预算及300血条件保持不变。

## 10. 后续几何定位

第9节当时未解决的距离偏差，随后通过八组分段对照复现并定位，详见 [几何调查](fixed_target_geometry.md)。组合退化实际YOLO路径中心高估16.85cm；灯条长度缩到真实投影约92.10%，上下端点各向内约1.96px。独立PnP消融只恢复真实灯条长度时，单板距离平均偏差由13.53cm降至0.93mm；只恢复灯条中心则仍约13.56cm。理想角点和保留实际关联/初值的真值影子拟合均无此系统误差。

原因涉及渲染完整发光外沿与精修二值轮廓端点定义的差异、亮度/模糊敏感性；当前PnP后的yaw优化不回算三维平移。尚未实施实物端点标定或新的生产校正，不直接减17cm或添加固定像素补偿；本轮定位结果不能当作实车偏差测量，也未重新评估命中率。
