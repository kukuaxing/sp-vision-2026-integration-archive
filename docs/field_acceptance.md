# 现场接续验收

当前后端为 Sentinel V2；历史 RMV 的三轴、轮速/拨弹反馈和档位不能直接套用。当前状态见 [status.md](status.md)，数值见 [current_parameters.md](current_parameters.md)。

1. 先恢复连续图像和姿态回传，记录 CRC、序号、boot/epoch 和帧率；设备枚举正常不代表链路有数据。
2. 确认相机/镜头/安装与所用标定一致，分别核对姿态方向、相机曝光时间与 IMU 时间含义。认证未完成时如实记录。
3. 由用户启动跟随检查，记录静态稳定性、目标切换、遮挡恢复、遥控接管和断连行为。
4. 弹速和命令到出膛延迟分别测量；请求写入串口、下位机许可、拨弹、实际出膛和命中分别统计。
5. 固定靶与旋转靶分开记录，包含距离、转速、目标尺寸、配置/模型/程序身份及原始画面。经验落点修正不是弹速实测。

本次维护只做复制、静态整理、构建和离线验证，不代替上述实车验收，也不由代理启动动作/发射。
