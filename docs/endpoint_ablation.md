# 端点更准却少中：几何、随动与时序的分离对照

## 本轮结论

新端点候选保持关闭，正式程序、YAML、PID与导航未改。本轮仅增加离线记录和诊断入口，没有启动机器人。

在所测双旋向子集中，有限云台滞后、相机随动和命令在发令后继续更新均未改变命中数，暂不支持把这几发差异归因于电机跟不上。更大的影响来自本场景**假设的出膛随机抖动**与发射机会选择；仿真中的25ms不是实车测量，不能据此诊断拨弹机构或修改真实延迟。

## 数据划分与防止误读

上轮新留出组旧556/600、新551/600。本轮将其中种子6011、初相位15°、双旋向各50发明确重新归为**诊断开发子集**，每个端点路径100发；不再将它当作新方案的独立验证。该子集旧92/100、新89/100。

新增逐发发令目标角度、出膛时的虚拟云台角度/目标角度、模型点和估计中心。默认路径重跑后逐字段复现原200条发射记录（标量差异<1e-9，布尔结果一致）；追加日志没有改变原发令行为。

完整1,200条旧/新下发轨迹用于冻结重放，新的六项对照共600条记录，其中200条是原轨迹复现。不能将它们说成1,800发独立的新验证。

## 1. 闭环分离：云台和相机反馈

| 条件 | 旧端点 | 新端点候选 |
| --- | ---: | ---: |
| 原有限响应，τ=60ms，相机随动 | 92/100 | 89/100 |
| 保持原有限响应，只固定虚拟相机姿态 | 92/100 | 89/100 |
| 相机继续随动，虚拟跟随响应改为瞬时 | 92/100 | 89/100 |

固定相机与瞬时响应都是明确改变条件的**消融实验**，不能拿其数值宣传生产改进。固定相机时投影与Solver使用同一固定姿态，保留原姿态偏差；没有给预测器真值角点/中心。瞬时响应没有取消观测、质量或发射门槛。

三组命中数相同，不代表观测、发令时刻或落点完全相同，也不能由这一个小子集排除所有实车随动问题。它只表明，这里3发差异未随上述干预消失。

## 2. 固定轨迹：只替换出膛时的跟随角度

对每个实验已生成的下发序列和随机误差，冻结其观测/门控结果，只在评估端替换虚拟云台分量，保留已抽取的枪口偏差和角散布：

- 分别消除Yaw、Pitch或双轴跟随误差；
- 将出膛朝向替换为发令时要求的朝向，检查等待出膛期间继续跟随的影响。

零时移下，上述四种干预对每个条件的100发均没有命中/脱靶翻转。默认有限响应时，出膛目标与实际角度误差的P95：旧Yaw约0.01281°、新Yaw约0.00116°；旧Pitch约0.01077°、新Pitch约0.01019°。候选的Yaw随动反而更稳定，不能用“新端点让电机更抖”解释这组差异。

这些是冻结轨迹的评估，未重新生成观测和控制，不是实车控制器可读取的未来状态。

## 3. 固定轨迹：出膛时刻敏感性

冻结上轮全部1,200条下发的角度、弹速与误差，仅把每次出膛时刻统一平移；不重新运行门控，也不重新选择参数：

| 出膛时刻相对原记录 | 旧端点命中/600 | 新端点命中/600 |
| --- | ---: | ---: |
| 提前20ms | 534 | 547 |
| 提前10ms | 552 | 555 |
| 提前5ms | 555 | 553 |
| 原时刻 | **556** | 551 |
| 晚5ms | 547 | 534 |
| 晚10ms | 539 | 518 |
| 晚20ms | 517 | 488 |

候选对较晚出膛更敏感；统一提前10ms也只有555/600，未超过旧原值556/600。**冻结物理出膛时刻的平移不等价于修改预测器延迟**，后者会改变选面、发令和后续观测，因此表里的-10ms不是上车参数。

零干预重放逐条与原几何计分一致；连续求交包含重力、转动平面、正面穿越与有限板尺寸，未放宽窗口。

## 4. 误差预算：已假设的随机性掩盖了多少收益

保持原下发序列和射线方向，只在评估端移除某一**已知仿真随机项**。延迟均值仍为340ms；原场景出膛标准差25ms、弹速均值22m/s和标准差0.3m/s、Yaw散布标准差0.12°、Pitch散布标准差0.2°。这些分布均为仿真假设。

| 冻结评估条件 | 旧端点 | 新端点 |
| --- | ---: | ---: |
| 原随机误差 | 556/600 | 551/600 |
| 仅将每发出膛延迟固定为原均值 | 587/600 | 586/600 |
| 仅将每发弹速固定为原均值 | 559/600 | 558/600 |
| 同时固定延迟与弹速 | 593/600 | 595/600 |

在这组冻结轨迹下，去除出膛抖动的影响明显大于去除弹速波动，原新旧5发差距缩为1发。这个结果支持优先调查时序重复性；它没有证明新端点普遍更差，也没有证明实车必有25ms抖动。

在有完整虚拟云台分量的100发子集中，移除角散布仅使旧92→94、新89→92；固定延迟时旧92→98、新89→98。继续同时移除多个随机项可出现100/100，这是被人为简化的误差预算，**不能作为新版本或实车命中率**。

此处延迟替换仍保留原时刻记录的射线，未重新积分相机与伺服路径；它是条件敏感性评估。第1—2节对跟随的独立干预为解释该近似提供了子集证据，不能将它扩展成所有工况的严格因果证明。

## 5. 发射机会与样本限制

候选在原600发中，预测命中相位绝对值小于3°的473发中443中；不小于3°的127发中108中；其中不小于9°的16发仅11中。边缘机会更敏感，但这是事后相关性，不能直接据此选出新门槛并拿同组自证。

5发差距按种子分解为6011贡献-4、7001贡献-1、8011贡献0。逐发14次旧中变新未中、9次反向改善；同种子/同轨迹内的记录有关联，不能把600发简单当作独立伯努利样本，随意给统计显著性结论。

下一项可验证方案应在**另一开发组**比较更靠近中心的发射机会，保持原新鲜观测/连续帧/姿态/限频/质量门槛，允许跳过不佳机会，并检查60秒内仍发满50发及完成300血耗时。候选冻结后换全新种子/相位验证；本轮没有默认启用任何新门槛。
